# Challenge.Gov Platform Configuration Guide

## Environment Variables

| Variable                    | Description                                                                                                                                                    | Expected Value Examples                                     |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| APP_DOMAIN                  | Rails app domain config                                                                                                                                        | app.cloud.gov                                               |
| AWS_ACCESS_KEY_ID           | Access key for S3, provided as a Cloud.gov Service                                                                                                             |                                                             |
| AWS_SECRET_ACCESS_KEY       | Secret Access key for S3, provided as a Cloud.gov Service                                                                                                      |                                                             |
| AWS_BUCKET_NAME             | Bucket Name for S3, provided as a Cloud.gov Service                                                                                                            |                                                             |
| AWS_REGION                  | S3 Bucket Access Region                                                                                                                                        | us-gov-west-1                                               |
| DATABASE_URL                | The standard formatted postgres URL composed from the components of username, password, hostname, and database name, as provided by the Cloud.gov RDS service  | postgres://username:password@hostname:port/database         |
| HOST                        | The external DNS name of the running platform                                                                                                                  | challenge.gov                                               |
| LOCAL_PROXY                 | Host and Port of the sidecar proxy relay                                                                                                                       | http://localhost:8888                                       |
| JWT_SECRET                  | a random string to validate the login flow and interop with the portal app                                                                                     |                                                             |
| LOCAL_PROXY                 | The local sidecar proxy that will relay to the egress proxy                                                                                                    | 127.0.0.1                                                   |
| LOGIN_CLIENT_ID             | The login client ID for the application in Login.gov                                                                                                           | urn:gov:gsa:openidconnect.profiles:sp:sso:gsa:challenge_gov |
| LOGIN_IDP_HOST              | The base URL of the IDP provider                                                                                                                               | https://idp.int.identitysandbox.gov                         |
| LOGIN_PRIVATE_KEY_PASSWORD  | The password to decrypt the private key used in the Login.gov OpenID connect flow                                                                              | password                                                    |
| LOGIN_PRIVATE_KEY_PATH      | The path within the code repository to the provide key for the application to use with Login.gov                                                               | environment_key.pem                                         |
| LOGIN_PUBLIC_KEY_PATH       | The path to the matching public key for the private key in LOGIN_PRIVATE_KEY_PATH                                                                              | cert.pem                                                    |
| LOGIN_REDIRECT_EVAL_URL     | The redirect URL for after Login.gov auth                                                                                                                      | https://challenge.gov/auth/result                           |
| LOGIN_SECRET                | a random string secret to use as part of the login validation loop with the portal app                                                                         |                                                             |
| LOGOUT_REDIRECT_EVAL_URL    | The redirect URL after logout from Login.gov                                                                                                                   | https://challenge.gov/auth/result                           |
| PHOENIX_URI                 | The base URL of the running portal application                                                                                                                 |                                                             |
| PROXYROUTE                  | The fully qualified URL for the upstream egress proxy with protocol, authentication, domain, and port. Used by the caddy sidecar                               |                                                             |
| PAGES_DOMAIN                | The domain name of the cloud.gov pages content                                                                                                                 |                                                             |
| PAGES_HOST                  | The https address of the cloud.gov pages content with no path                                                                                                  |                                                             |
| PAGES_BASE_URL              | The base page path for the root of the cloud.gov pages static content, only needed when using preview links                                                    |                                                             |
| RAILS_ENV                   | The environment to boot the app for                                                                                                                            |                                                             |
| SMTP_SERVER                 | The DNS or IP address of the SMTP server to connect to. May be a TCP relay proxy                                                                               |                                                             |
| SMTP_PORT                   | The port of the SMTP server to connect to. May be a TCP relay proxy                                                                                            |                                                             |
