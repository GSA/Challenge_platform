# Challenge.Gov Platform Configuration Guide

## Environment

This is the platform for the future of challenge.gov. This is designed to be the main responding application at challenge.gov. This platform proxies the static cloud.gov pages through its default routes to provide easy to manage content. The challenges themselves are managed by the portal, as are submissions and users and some content. The platfrom focus is currently on evaluation of submissions.

The environment for the application deployment is cloud.gov. There are 3 planned environments.
